# migrator-skills

Скіли Claude Code для КЕРУВАННЯ [Migrator](https://github.com/BusinessAutomationFramework/Migrator) -
схемо-орієнтованим інструментом переносу даних для баз 1С:Підприємство /
BAF - створення завдань переносу, їх безпечний запуск, і рігорозна
перевірка результату. Доповнює `baf-skills` (загальні знання 1С/BSL),
не дублюючи їх.

## Скіли

- [`migrator-new-task`](.claude/skills/migrator-new-task/SKILL.md) -
  покроковий гайд створення нового завдання переносу: реєстрація кореня
  завдань, запуск `migrator suggest` для заготовки `related_catalogs`,
  написання повного `schema.yaml`, валідація, перший обмежений
  смоук-тест.
- [`migrator-run-task`](.claude/skills/migrator-run-task/SKILL.md) -
  дисципліна навколо реального запуску `python -m migrator run`:
  перевірка ПЕРЕД запуском на завислу сесію `1cv8.exe`, валідація схеми
  до ~20с холодного старту BridgeTool, планування тайм-ауту (кожен
  COM-запит - головний ТА кожен каскад ТА кожна таблична частина -
  коштує фіксовано ~20-30с незалежно від кількості рядків), і як
  правильно читати підсумок часткової невдачі.
- [`migrator-verify-transfer`](.claude/skills/migrator-verify-transfer/SKILL.md) -
  повторно використовуваний скрипт (`scripts/verify_transfer.py`), що
  ЗАНОВО читає джерело й приймач і звітує відсутні/зайві записи,
  польові відмінності (розділяючи очікувані категорії - скидання полів
  групових записів, квірк серіалізації "порожньої" дати через
  `Формат()` - від справжніх прогалин), і вибіркову перевірку кількості
  рядків табличних частин. Не довіряйте голому "Успешно: N" - саме це
  підтверджує, що перенос СПРАВДІ відбувся.

## Походження

Створено паралельно з [Migrator](https://github.com/BusinessAutomationFramework/Migrator)
самим, узагальнивши підхід до перевірки, використаний для
acceptance-тесту довідника "Склади".
